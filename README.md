# EmHe.Sweets — меню

Локальный сайт с категориями, поиском и корзиной. Заказ открывается в WhatsApp как готовое сообщение; пользователь отправляет его сам.

## Запуск

Нужен Node.js. Установка зависимостей не требуется.

    npm start

или:

    node preview-server.cjs

Откройте адрес из терминала. Если 4173 занят, сервер автоматически попробует следующий порт. Для остановки — Ctrl+C.

После изменения файлов обновите страницу. Сервер читает исходники из корня проекта.

## Ассортимент

Редактируйте menu-data.js:
- categories — категории, их названия и иконки;
- products — блюда, описания, порции, цены и пути к изображениям;
- whatsappNumber — номер владельца в международном формате, только цифры.

Ассортимент и цены перенесены из имён фотографий в папке «десерты» на рабочем столе. Названия проверены. Фотографии приведены к одному стилю с помощью image_gen; исходники сохранены. Полные версии находятся в «десерты/Обработанные», лёгкие копии — в assets/catalog. Цена 100 ₽ для банана, граната и клубники в шоколаде относится к 1 штуке. Неизвестный вес и объём не указаны.

Если номер пустой, WhatsApp предлагает выбрать получателя. Для прямого заказа владельцу заполните whatsappNumber.

Используйте уникальные id для категорий и товаров. Поле category у товара должно совпадать с id категории. Цена задаётся числом в рублях.

Корзина хранится в localStorage браузера. Сервер и база данных для обработки заказов не используются.

## Файлы

- index.html — структура меню и корзины;
- styles.css — оформление и адаптация под мобильные экраны;
- menu-data.js — ассортимент и номер WhatsApp;
- app.js — поиск, фильтры, корзина и сообщение заказа;
- assets — локальные изображения;
- preview-server.cjs — локальный сервер.

Папка dist содержит готовую статическую версию для хостинга. Локальный сервер использует файлы из корня проекта.

## Публикация на хостинге

Сайт не требует сборки или серверной базы данных. Для ручной публикации загрузите содержимое dist на статический хостинг.

Для подключения репозитория к Netlify оставьте Build command пустым, а Publish directory укажите dist. После изменения меню, оформления или фотографий синхронизируйте соответствующие файлы в корне проекта и в dist.

Кнопка заказа открывает WhatsApp с готовым сообщением на номер из menu-data.js. Отправку сообщения подтверждает сам покупатель.
